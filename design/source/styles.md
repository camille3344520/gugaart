# 咕咕画报 · B1「头版」/ B2「立体书」

在第一组 **B 画报**上继续做的两个手机版本。两版都把 **C 流光的三维封面流**融进了画报，都加入了咕咕嘎嘎的吉祥物，都补全了界面。

- 入口：`index.html`（双击即可，需要支持 WebGL2 的 Chromium 内核浏览器）。左栏切 B1 / B2，有界面目录和「可以玩的」清单；右边是这一版的全部界面，都是活的，鼠标 = 手指。每台手机下面的小按钮切换这个界面的状态（筛选打开、加载中、暂停……）。
- 单看一屏：`index.html?v=b1&p=home&shot=1`，`p` = `home / lib / search / series / movie / person / me / settings / player`，状态用 `&st=`，滚动位置用 `&scroll=`。
- 截图：`shots/<版本>-<界面>[-状态].png`，每版 41 张（9 个界面的各个状态 + 交互中的画面），另有两张整页 `_gallery-b1/b2.png`。重拍：`node tools/shots.js [过滤词]`。

## 两版共同遵守的

- **底部标签栏和旁边的搜索圆钮**由现成的液态玻璃引擎渲染：`js/engine.js`、`js/core.js`、`js/glass.js` 三个文件从 `fable-styles/js` 原样复制，一个字节没改。按住选中的标签拖，透镜会抬起、放大文字、松手回弹。
- **片名用 TMDB clearlogo**：封面、两个详情页、播放器顶栏、搜索最佳匹配、人物页作品都是 logo 原图，只缩放和加投影。列表里的小片名用宋体。
- **海报和剧照不被盖**：海报流正中那张始终正对、不压任何标签；logo 只搭在海报下沿十几个像素；剧集详情的剧照是整幅 16:9、放在顶栏下面，返回 / 收藏按钮不压在人脸上。原 B「新刊」里压在海报左下角的大号数字挪到了海报下面。
- **状态栏不叠字**：标签页顶上是一条实心的纸色带，滚动内容从它下面经过，不是渐隐；详情、人物、设置的顶栏（状态栏 + 返回一行）同样是实心的。只有电影详情顶部是衬纸（没有文字），滚过之后顶栏变实。
- 只有深色；返回在左上、选项在右；播放器里有收藏和锁屏。
- **她不遮挡内容**：只待在专门留给她的格子里（每版见下），不弹气泡、不做浮层；她说的话写进留给她的那一行字里。播放时不出现，暂停才坐进顶栏留给她的一格。
- 现有分层立绘做得到的（眼睛跟手指、眨眼、被戳扑翅膀 + 吃惊、举翅膀）用真图（`js/mascot.js` 是网页版骨架的画布移植）；做不到的新姿势用线稿轮廓占位，旁边标了「轮廓占位 · 动作」，清单在文末。
- 高清素材：海报、剧照、横版缩略全部来自 `fable-styles-b/hires`。只有 3 张演员头像、3 张分集缩略和播放器那一帧沿用旧图（高清包里没有）。

## B1 · 头版（Front Page）

**一句话**：报摊上立着一排今天的封面，翻到哪一期，整本画报就换成那一期的专色；她是这本画报的主编。

**相对原 B 改了什么**
- 首页的整幅剧照封面换成了三维海报流（见下一条）；期号从右下角挪到左边，变成跟手滚动的里程表；多了一行「主编手记」。
- 朱红不再是固定的：**每期一个专色**，取自正中那张海报（饱和、提亮到在墨黑纸上读得清），栏目名、编号、进度线、海报的投影一起换。进了详情页专色跟着那部片子走。玻璃底栏选中的小圆点保持朱红。
- 详情页：剧照改成顶栏下面的整幅 16:9 图版 + 图注；收藏旁边多了印章位；分集目录每行行尾多了校对格。
- 新增界面：片库（海报墙 + 筛选页）、电影详情（多版本）、人物页、我的、设置、加载和空状态；播放器补了暂停和选集两个状态。

**C 的封面展示怎么融进来**
- 「本期封面」就是 C 的海报流，换成了画报的样子：直角、细米白边、没有圆角和流光背景。正中一张正对你，两侧向后转 54°、压暗。
- **跟手**：按住左右拖，海报跟着手指连续移动（不是点一下跳一张），松手带惯性吸附；拖得越快海报被甩得越斜。
- **纵深和视差**：手指（鼠标）在海报上移动，正中那张朝手指倾斜、有一道高光；片名 logo 浮在海报前面，反方向移动。
- **染色**换成了画报的说法——专色：C 是整屏流光，这里是海报背后一小片专色的晕 + 所有红字换色，纸还是墨黑的。
- 期号（Georgia 斜体大数字）像里程表一样跟着手指滚，翻过半张时导语、类型行、续看按钮、主编手记一起换。

**她是谁、放在哪、为什么不挡**
- 角色：**主编**。画报是她编的，所以她写手记、盖收藏章、画校对勾、在片尾署名。
- 位置（都是页面流里专门留的一格，跟着页面滚走）：
  - 首页封面区最下面的「主编手记」一行：左边一个圆形署名照（活的立绘），右边一行她的话。
  - 剧集详情引语下面的「主编按」一行；我的页的「读者证」左格。
  - 播放器顶栏右侧、收藏键左边的一格：播放时是空的，暂停才出现。
  - 轮廓占位：下拉条里摇印刷机、片库加载排版、搜不到摊手、搜索空状态举笔、下载为空捧白纸、首页末尾打盹。
- 不挡的原因：这些格子本来就是版面上的一栏（署名、手记、图注），不是叠在内容上的层；她做动作不出格子。

**互动清单**（demo 里都能操作）
1. **翻封面** → 按住海报流拖，期号跟着手指滚、专色换色，松手后导语错开半拍换上来，她眨一下眼、手记换一句。
2. **收藏 → 主编盖章**：点「收藏」，朱红的「藏」字章从大到小“咚”地落进链接旁预留的虚线印章位，她举起翅膀，手记那行写「盖章了」；再点一次章褪掉。首页、剧集详情、电影详情都有，顶栏的爱心同步。
3. **标记已看 → 校对勾**：分集目录点行尾的小方格，一笔红色校对勾划出来、集号被划掉；再点擦掉。
4. **下拉刷新 → 付印新刊**：首页顶部往下拖，报头上方拉开一条（内容整体下移，不盖东西），她摇印刷机手柄，进度线拉满后松手，VOL. 318 滚成 319，封面回到第一期。
5. **换集**：分集目录点任意一行，专色标题跳到那一行，续看按钮和进度线改成那一集，「主编按」里她说一句。

**推广到电脑和电视**
- 电脑：宽屏做成跨页——左页是海报流（可以同时正对 1 张、斜放 4 张），右页是期号 + 导语 + 目录；鼠标悬停就倾斜，滚轮翻期。主编手记放在右页页脚。详情是两栏正文，印章位在标题旁。
- 电视：海报流横贯上半屏，遥控器左右翻期，期号放大到 10 英尺可读；专色换色在大屏上很出效果。她只留在首页手记和暂停两处，竖排小字和校对格去掉（遥控器上标记已看走菜单键）。

**落地难度**：中。海报流是 `graphicsLayer` 的 rotationY / cameraDistance + 一个连续的 pager 位置；专色 = 取色后限制亮度和饱和度（要准备灰海报的兜底色）；印章和校对勾是两段很短的 Canvas 动画。风险：宋体字库体积；专色遇到脏色海报要有黑名单色相；导语需要内容（没有 tagline 时退回类型行 + 简介第一句）。

## B2 · 立体书（Pop-up）

**一句话**：封面是一页翻开的立体书——衬纸、立起来的海报、最前面的片名，一共三层；她是夹在书里的书签小人。

**相对原 B 改了什么**
- 原 B 是「印刷品」，B2 是「纸做的东西」：海报、剧照、头像都有一圈米白的纸边和落在纸面上的影子，片库的海报墙每张微微歪一点；列表改成图在左、编号在标题上方。
- 朱红保持不变，只用在丝带、书签角、编号上。
- 首页封面换成立体书页（见下一条）；续看按钮左边多了她站的位置和她的一行小字。
- 详情页：收藏旁边是丝带槽，分集目录每行行尾是折角位，正在看的那一集左边有红色书签角；「我的」页的读者证是一张浅色的借书卡。
- 新增界面同 B1。

**C 的封面展示怎么融进来**
- 一页立体书有三层，对应 C 的三样东西：
  - **衬纸**（最远）= C 的整屏染色：这部片子的剧照虚化、压暗后铺满图版，翻页时从右往左换（保留原 B 的翻页）。
  - **海报**（中间）= C 的海报流：正中一张带白边立着、正对你；两侧的不是向后转，而是**向后躺倒**（像立体书里还没立起来的纸片），拖动时躺着的那张慢慢立起来。
  - **片名 logo**（最近）= C 的前景 logo，搭在海报下沿。
- **跟手**：同样是按住连续拖、带惯性吸附。
- **视差**：手指移动时三层各走各的——衬纸跟着走一点，海报倾斜，logo 反向走得最多；图版中间有一道很淡的书脊线。

**她是谁、放在哪、为什么不挡**
- 角色：**书签小人**。你看到哪儿，她就替你夹在哪儿；她是一张带白边的剪纸，站在一小条纸托上。
- 位置：
  - 首页「续看」按钮左边的一格（按钮因此短一截，不是叠上去的），下面一整行小字是她的话。
  - 剧集 / 电影详情播放按钮左边同样的一格 + 一行小字；我的页借书卡左格。
  - 播放器顶栏右侧一格，暂停才出现。
  - 轮廓占位：下拉条里从书页后面探头、片库加载翻书、搜不到摊手、搜索空状态举放大镜、下载为空抱书打盹、首页末尾合书挥手。
- 不挡的原因：她占的是按钮让出来的宽度和单独一行字；红色书签角画在行左边的页边空白里，不压缩略图。

**互动清单**（demo 里都能操作）
1. **翻封面 → 立体书翻页**：按住海报拖，离开正中的那张向后躺倒，新的一张立起来，衬纸换页，页码 03 / 06 跟着换。
2. **收藏 → 夹丝带**：点「收藏」，一条朱红丝带从链接旁预留的小槽里垂下来、弹一下，她举翅膀，小字写「丝带夹好了」；再点收回去。
3. **标记已看 → 折角**：分集目录点行尾虚线的小角，纸角折下来，那一集的图变淡；再点翻回去。
4. **下拉刷新 → 拉纸条**：首页顶部往下拖，她从书页后面探出头，探多少跟着手走，拉够了松手换一批封面。
5. **续播 / 换集 → 挪书签**：首页目录或分集目录点一行，红色书签角滑到那一行的页边，续看按钮跟着改，她在小字里报一声。

**推广到电脑和电视**
- 电脑：最适合。宽屏就是一本摊开的书：左页衬纸 + 立体海报，右页目录；鼠标移动的三层视差在大屏上很明显，滚轮翻页时海报一张张立起来。书签角放在窗口左缘。
- 电视：焦点移到哪张，哪张立起来，衬纸换页；纸边和影子在 10 英尺距离要加粗。折角、丝带保留（遥控器确认键触发），她只在首页和暂停出现。

**落地难度**：中到高。躺倒的海报要 rotationX + 底边为轴，和 rotationY 叠加时注意相机距离；衬纸要给每个条目预先生成一张小的虚化图（进图片缓存）；白边和纸影在海报墙上数量多，要用一次绘制完成而不是每张一层。风险：没有剧照的条目衬纸要退回海报取色；手机上三层视差需要陀螺仪，没有时退成只跟拖动。

## 我更推荐哪个

推荐 **B1 · 头版**。

1. 它离用户看中的原 B 最近：还是细线、大字、斜体数字，只是封面活了、颜色活了。B2 把气质从「印刷品」推到了「手工纸艺」，更可爱，但离原来的冷静远了一步。
2. 专色是一个很省的大效果：只换一个颜色变量，整本画报就跟着海报变，电视低端芯片也没有负担；B2 的衬纸要多一套虚化图。
3. 主编这个角色给了她「说话的理由」（手记、按语、盖章），又天然待在署名栏里，不抢内容。
4. 实现风险低：B1 的海报只绕一个轴转；B2 的躺倒 + 白边 + 纸影在海报墙上的开销要实测。

可以从 B2 借到 B1 的两样：**折角**（比校对勾更好认，适合电视）和**书签角**（标出正在看的那一行）。

## 文件

- `index.html` 入口；`css/shell.css` 页面外壳；`css/hb.css` 两版共用的画报样式；`css/b1.css`、`css/b2.css` 各自不同的部分。
- `js/app.js` 外壳（素材、取色、弹簧、拖动滚动、播放器逻辑）；`js/kit.js` 两版共用的部分（海报流、下拉刷新、片库 / 搜索 / 详情 / 人物 / 我的 / 设置 / 播放器）；`js/b1.js`、`js/b2.js` 各自的首页、她的台词和姿势。
- `js/engine.js`、`js/core.js`、`js/glass.js`、`js/sprite.js`：从 `fable-styles/js` 原样复制（玻璃引擎、材质表、适配层、图标）。
- `js/mascot.js`、`js/poses.js`：从 `fable-styles-b/js` 复制；`mascot.js` 加了一行（翅膀离开静止位时隐藏垫在下面的静态图），`poses.js` 加了几个道具（稿纸、笔、书、手柄、丝带等），都有 `[huabao]` 标记。
- `js/assets.js`：`node tools/build-assets.mjs` 生成的图片包（13 MB，base64；玻璃引擎在 `file://` 下只能读 data URL）。
- `tools/shots.js` + `tools/shotlist.js`：截图和交互自查（无头 Chrome + CDP，自带独立的临时 user-data-dir，等图片解码和引擎就绪后才截）。

已知的小出入：
- 玻璃折射的是页面内容的一份重绘（适配层自带的画法），只认图片、纯色、线性渐变、文字和图标；海报的白边、轻微旋转、线稿轮廓在玻璃里是近似或缺席的。真机上着色器直接取屏，没有这个问题。
- 分集缩略只有 3 张旧图轮流用，演员头像是 200 px 的旧图（人物页按 128 px 显示）。
- 演示数据是写死的：片库筛选和搜索是真的在 20 部片子里筛，但媒体库的总数（1,875 等）是摆的数字。
