# 咕咕嘎嘎 · B1「头版」· 电视端（1920 × 1080，遥控器）

- 入口：`index.html`（双击即可，要支持 WebGL2 的 Chromium 内核浏览器）。左栏是界面目录和「可以玩的」，右边每个画板是一块真的 1920 × 1080 屏幕（缩小显示），下面的小按钮切状态，再下面一行灰字是这一屏的方向键路径。
- 点一下画板让它拿到键盘，然后：方向键 = 遥控器方向键，Enter = 确定（按住半秒 = 长按确定），Backspace / Esc = 返回，M = 菜单键。
- 单看一屏：`index.html?p=<界面>&st=<状态>`，加 `&shot=1` 关掉动画（截图用）。界面名：`home discover libs lib colls coll search series movie person me menu settings servers update player`。
- 截图：`shots/<界面>[-<状态>].png`，原尺寸 1920 × 1080。重拍：`node tools/shots.js [过滤词]`（无头 Chrome，自带临时 user-data-dir，等图片解码和玻璃引擎就绪才拍）。
- 图片：`node tools/build-assets.mjs` 把 `../data/img` 的每张图转成 `assets/<名>.js`（data: URL，玻璃引擎在 `file://` 下只能读这种），一屏只加载它用到的；同时生成 `js/data.js`（library.json + extra.json + extra2.json）。

## 相对手机版 B1 改了什么

1. **版式重排，不是放大**。
   - 首页是一张横向的头版：左栏期号 / 片名 logo / 导语 / 按钮 / 主编手记，右栏三维海报流，背后整幅铺着这一期的剧照。
   - 焦点进了目录，封面区收成「焦点预览」：焦点到哪张卡，上半屏就换成那部片的剧照、logo 和导语。
   - 详情页一屏一件事：第一屏整幅剧照，第二屏选季 + 分集横排，第三屏演职人员 + 相似，上下键整屏翻。
2. **报头**按三端统一稿：左 `VOL. 318`，中「咕 咕 ◉ 嘎 嘎」（宋体 900，字距 0.34 em，◉ 是从品牌图圆形裁出的企鹅头，直径 = 字高 × 1.15，外圈 1 px 米白线），右日期。上线 2 px 米白，下线 2 px、18 %。**电视多了一个时钟**（日期后面的斜体 `21:47`）：电视没有状态栏，时钟只能放这里；内页的页眉右端也有。
3. **演员头像全部彩色**（详情、搜索、人物页、同剧的人）。
4. **整幅铺满**用在：首页封面区背后、首页焦点预览、发现的「今日一篇」、合集详情、剧集详情、电影详情、人物页、播放器片尾「下一集」。做法：图从屏幕最顶端铺起，页眉压在图上；左侧和底部各一层暗角，文字只放在暗角里；说明这是哪一集剧照的小字改成右上角横排（电视上不用竖排）。亮图（网球王子的白天空）会自动把暗角加深。
5. **去掉的**：屏幕上的返回按钮（返回键负责）、竖排小字、行尾的校对小方格（改成长按确定菜单里的「标记已看」，勾画在分集卡右上角）、下拉刷新手势（改成报头上的「付印新刊」）、手机底部标签栏（改成左侧玻璃侧栏）。
6. **新增的界面**：发现、媒体库列表、合集列表 / 详情、长按菜单、设置 9 个分区、服务器 / 登录、更新提示、播放器的快进 / 跳过片头 / 片尾 / 缓冲 / 出错、网络断开、再按一次退出。

## 布局规则

- **安全边**：左 136（其中 28 – 104 是玻璃侧栏），右 96，上 40，下 48。所有文字和焦点都在这个框里；只有整幅剧照、横排卡片的下一张可以出框。
- **海报墙**：7 列，卡宽 214（2 : 3 = 214 × 321），列距 32，行距 36；筛选栏打开时挤成 5 列。**横排卡**：续看 312 × 176，分集 400 × 225，演员 170 × 226。
- **字号阶梯**（px）：22 最小（图注、提示）/ 26 正文 / 30 导语、按钮 / 38 栏目名 / 56 页名 / 88 – 124 大标题 / 150 期号。宋体正文一律 600 以上，标题 900；Georgia 斜体只用于数字和英文小标签，最小 20。细线：通栏主线 2 px 米白，分隔线 1 px、20 %。
- **专色**：取焦点 / 当前那张海报最强的色相，推到亮度 0.62；灰海报退回朱红。栏目编号、进度线、热力条、小标签用专色。**焦点、印章、校对勾永远是固定的朱红 + 米白**，不跟专色走，保证任何海报上都认得出。
- **片名**：有 clearlogo 用 logo；黑色笔画的 logo（网球王子、头文字D）自动垫一张米白衬纸，略微倾斜，像贴上去的剪报；没有 logo 的（男人没有好东西、沙丘虫暴、全部合集）退回宋体，按字数分四档字号（≤ 5 字 100，≤ 7 字 72，≤ 10 字 52，更长 44 两行）。
- **滚动**：横排里焦点卡永远停在左起第一格，栏内容滑动，滑过去的卡淡出（不在侧栏底下留半个字）；竖向按「栏」或「屏」对齐，页名栏 / 页眉是实心的，内容不从它下面露半行。首页封面状态下目录只露图不露字。

## 焦点规则

- **焦点的样子**：米白实底（或米白 4 px 框）+ 四角朱红校对角 + 略微抬起（卡片 ×1.08，按钮 ×1.04）。一屏里只有焦点是米白实底的，3 米外一眼能找到。
  - 图片卡：米白框 + 校对角 + 投影，下面的片名由灰变白。
  - 按钮、列表行、字母键、选项：整块变米白底、墨字。
  - 米白纸条上的菜单（长按菜单、更新号外）反过来：焦点是墨底米白字。
  - **玻璃上的焦点**（侧栏展开、跳过片头）：玻璃里一张米白纸条、墨字，周围一圈仍是折射的玻璃。当前页在侧栏上是亮图标 + 朱红小圆点。
- **默认焦点**：首页 = 海报流；详情 = 续看 / 播放；片库 = 第一张；搜索 = 字母盘；播放器控件 = 播放键；对话框 = 主操作。
- **通用路径**：任何页面一路按左到头 = 展开侧栏（焦点落在当前页那一行）；返回键 = 收起最上面一层（菜单 → 面板 → 下一屏回上一屏 → 上一页）；长按确定 = 焦点项的菜单；菜单键 = 这一页的选项（片库是筛选 / 排序）。
- 每一屏的具体路径写在画板下面那行灰字里，也在各 `js/s-*.js` 的 `path` 字段。

| 刷新 | 封面上按上到报头 `VOL.`，确定 | 她摇印刷机（轮廓占位），`VOL. 318` 滚成 `319`，封面回到第一期 |

| 调字幕 / 倍速 | 播放器按下，上下换功能、左右改值 | 画面缩到左边，页边一栏当场改，字幕实时变 |
| 进导航 | 一路按左 | 玻璃侧栏长成一张目录页 |

## 咕咕嘎嘎放在哪、为什么不挡

她是主编，只待在版面上专门留给她的格子里，格子是页面流的一部分，不叠在内容上；没有弹出层，没有全屏角色。

| 位置 | 做什么 |
|---|---|
| 首页封面区「主编手记」一行（圆形署名照 + 一句话） | 眼睛会眨、翻期时换一句、收藏时举翅膀；付印新刊时这一格换成摇印刷机的轮廓 |
| 剧集详情第二屏右下「主编按」 | 跟着焦点那一集说一句（停在哪、有没有剧照） |
| 人物页名字下面一行 | 服务器没有生平时由她补一句 |
| 记录 / 收藏的「读者证」 | 署名照 |
| 设置 · 关于 | 署名照 |
| 更新号外左下角 | 署名照 + 一句为什么值得装 |
| 播放器顶栏右侧一格 | **只有暂停时**才坐进来；正在播放的画面上不出现 |
| 轮廓占位（待生图） | 片库加载、筛不到 / 搜不到 / 连不上、搜索空状态、收藏为空、首页最末尾、片尾看完一集 |

## 哪些是编的

- 字幕和弹幕的文字、弹幕热力条的形状。
- 盗梦空间的另外两个版本（2160p / 12.4 GB）；真实数据里每部电影只有一个版本。
- 播放器里的画质三档、音轨第二条、倍速、片头片尾的位置、缓冲速度、出错的错误码。
- 记录页按「今天 / 昨天 / 更早」的分组（服务器给的继续观看没有日期）；收藏的 10 部；读者证的期数。
- 发现页的题材 / 年代索引项、「今日一篇」的挑选；高分榜是真实评分。
- 搜索的「最近搜过」；拼音首字母是手写的一张小表（只覆盖数据包里的片名）。
- 服务器名（家里的片库 / 朋友的片库 / 旧硬盘）、账号名（影迷 / 家人 / 访客）、设置里的各个取值、更新号外的版本说明、二维码图案（不编码任何内容）。
- 主编手记和主编按的每一句话；首页 10 期封面的挑选和顺序。
- 航海王除第 1 季前 60 集、第 21 季前 30 集、第 22 季以外的分集只有集号（数据包里没有），画板上显示成编号空卡。

## 已知的出入

- 玻璃折射的是页面内容的一份重绘（适配层只认图片、纯色、线性渐变、文字、图标）；三维转过去的海报、径向光晕在玻璃里是近似的。真机上着色器直接取屏。
- 画板之间不连通：在一个画板里按确定「打开详情」只提示去看哪个画板。
- 字母盘的「123」数字盘、设置的下一级页面、添加服务器的地址输入没有画（地址输入和登录键盘是同一个键盘）。
- 片库海报墙的片名最多两行，更长的截断（全名在长按菜单和详情里）。
