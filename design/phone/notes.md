# 咕咕嘎嘎 · B1「头版」· 手机端

- 入口：`index.html`（双击即可，需要支持 WebGL2 的 Chromium 内核浏览器）。左栏是界面目录（15 组）和「可以玩的」清单；右边是全部画板，都是活的，鼠标 = 手指。每台手机下面的小按钮切换这个界面的状态。
- 单看一屏：`index.html?p=<界面>&shot=1[&st=<状态>][&scroll=<px>]`。界面 id：`home discover libs wall sets set search series episode movie person hist favs me settings servers update player`。
- 画板：竖屏 412 × 905 CSS 像素（× 3.5 = 1440 × 3168），播放器横屏 905 × 412（3168 × 1440）。
- 截图：`shots/<界面>[-状态].png`，全部按 1440 × 3168 / 3168 × 1440 原尺寸输出。重拍：`node tools/shots.js [过滤词]`（清单在 `tools/shotlist.js`）。
- 数据：`node tools/build-assets.mjs` 把 `../data/*.json` 和 `../data/img/` 打进 `js/data.js`、`js/assets.js`（base64，玻璃引擎要从画布读图，`file://` 下只能用 data: 地址）。
- 玻璃：`js/engine.js`、`js/core.js`、`js/glass.js` 从 `fable-huabao/js` 原样复制，一个字节没改。只有底部悬浮标签栏和旁边的搜索圆钮是玻璃，其余全是画报自己的语言。

## 1. 相对 B1 改了什么

**用户点名的三条**
1. **演员头像彩色**：演职人员、同台、搜索里的演员、人物页肖像全部去掉了灰度滤镜。缺照片的演员是一块带姓氏的斜纹空版（《男人没有好东西》14 人里 8 人没照片）。
2. **报头改成「咕咕嘎嘎」**：`VOL. 318｜咕 咕 ◉ 嘎 嘎｜十一月十四日`。排法和原报头一样（上粗线、下细线、左斜体期号、右日期），中间四个宋体字，正中嵌一枚 24 px 的圆形企鹅徽记——从品牌图里连帽衫的企鹅头（白眼圈 + 黄喙）圆形裁出来，外面一圈米白细线。首页、服务器 / 登录页用完整报头；发现 / 片库 / 我的三个标签页沿用同一条报头的排法，中间换成页名。**电脑、电视请按这个排：四个字 + 正中徽记，字距 0.34 em，徽记直径 ≈ 字高 × 1.15。**
3. **整幅铺满**：见下一节。B1 原来「顶栏下面框起来的 16:9 图版 + 图注」和电影页「浮起来的海报」都拿掉了。

**整幅铺满用在哪**
| 界面 | 铺的是什么 | 按钮和字怎么放 |
|---|---|---|
| 剧集详情 | 剧照，412 × 420，从屏幕最顶端开始 | 状态栏、返回 / 收藏 / 更多压在图上（按钮自带 52 % 墨底 + 顶部一条暗角）；栏目行、片名 logo、评分接在渐隐处；右缘竖排小字「剧照 · 第 5 集《…》」 |
| 单集详情 | 这一集的剧照 | 同上；集名是宋体大字 |
| 电影详情 | 剧照，412 × 430 | 同上；logo 下面接宣传语 |
| 合集详情 | 合集题图（没有就取第一部的剧照，竖排小字写明取自哪部） | 同上；合集没有 logo，用宋体 |
| 人物页 | 彩色肖像，412 × 540 | 大名 54 px 压在渐隐处 |
| 首页封面区 | 当前这一期的剧照（虚化、压暗），从状态栏一直铺到期号 | 海报流浮在它前面；翻期时跟着手指交叉淡入 |
| 发现 | 榜首的剧照，412 × 476 | 报头压在图上，大号斜体「1」+ logo 在渐隐处 |
| 播放器 · 看完一集 | 这部剧的剧照铺满横屏，两侧压暗 | 左「本集完」，右下一集 |
| 播放器 · 暂停 | 画面本身就是整幅，只压暗 18 % | 她坐进顶栏的一格 |

- **主体不被挡**：每部片子有一个 `object-position`（`s-detail.js` 的 `POS` 表：主体在图里的位置），竖屏裁切按它取景；按钮固定在左上 / 右上两个角，40 × 40，脸在两个按钮之间和下方。真实应用里这张表 = 图片的焦点（没有焦点数据时默认取上三分之一）。
- **状态栏不叠字**：顶栏在图上是透明的，滚动内容里的第一行字到达顶栏下沿之前（各页的 `data-solid` 阈值），顶栏变成实心纸色并出现页名；竖排图注在滚动 50 px 内淡出，不会钻到按钮下面。首页、发现的状态栏只要滚动 2 px 就变实心。
- **渐隐带里不露半行字**：图的下 58 % 是渐隐，文字从渐隐的 70 % 处（已经接近纸色）才开始；长简介折叠成整 6 行（行高 29 px × 6 = 174 px）。

**其余改动**
- 长屏多出来的 61 px：首页海报从 196 × 294 放大到 220 × 330，期号 62 → 66 px，各区之间的间距放开；两侧页边仍是 24。
- 标签栏从三格变四格（首页 / 发现 / 片库 / 我的），292 × 56，搜索圆钮 56，都悬在离底 18 px 处。**往下读（滚动）时标签栏和搜索钮一起沉到屏幕外，往回滚 8 px 就回来，滚到底也回来。**
- 片名 logo 的三种兜底：① 黑色笔画的 logo（头文字D、网球王子）会消失在墨黑纸上 → 运行时量一下 logo 的不透明像素里暗色占比，超过 30 % 就把它印在一张米白纸条上；② 没有 logo（男人没有好东西、所有合集）→ 宋体大字，字号按字数分四档；③ 英文合集名 → Georgia 斜体。
- 新增界面：发现、媒体库列表、合集列表 / 详情、单集详情、记录、收藏、设置首页 + 9 个分区、服务器 / 添加 / 登录、更新提示；播放器补齐到 19 个状态；系统态两个。
- 全部内容换成服务器上的真实条目（见第 6 节哪些是编的）。

## 2. 布局规则（手机 412 × 905）

**网格**
- 页边 24；正文栏宽 364。状态栏 46，高于它的任何固定条都是实心纸色或压在整幅图上。
- 标签页（发现 / 片库 / 我的 / 搜索）：状态栏 46 → 报头 44（上 8）→ 内容。推入页（详情、设置、记录……）：状态栏 46 + 返回行 50 = 顶栏 96。
- 返回永远在左上，选项在右上；按钮是 40 × 40 的方框（1 px 米白线），触控热区 48。
- 列表行：编号栏 40 + 文字 + 缩略图 104 × 58（16:9）或海报 46 × 69；行高 ≥ 86；行间 1 px 细线。
- 海报墙：3 列 × 110 × 165，列距 17，行距 22；片名最多两行，第二行年份 / 题材。
- 横向海报带：128 × 192，间距 16，第一张左对齐页边，最后一张露半张提示可滑。
- 底部安全区：最后一个区块下面留 150，保证末尾内容能滚到标签栏上方。

**字号阶梯**（宋体 = Noto Serif SC / 思源宋体；数字 = Georgia 斜体）
| 用途 | 字号 |
|---|---|
| 人物大名 / 设置分区名 / 欢迎页标题 | 54 / 42 / 44，宋体 900 |
| 期号、评分、榜单名次 | 66 / 60 / 132，Georgia 斜体 |
| 单集名、合集名（无 logo 的片名） | 34（长的 26），宋体 900 |
| 区块标题「目录」「分集」 | 22，宋体 900 + 11 斜体英文小标 |
| 列表行标题 | 17，宋体 700；正文导语 15 / 行高 29 |
| 列表副行、按钮旁说明 | 12 – 13 |
| 栏目行（专色、字距 0.3 em） | 10.5 |
| 最小字（图注、轮廓占位说明） | 9.5，只用于非必读信息 |

**颜色**：纸 `#100E0B`、字 `#EFE6D4`、次要字 64 %、弱字 40 %、细线 18 %；专色取自当前海报（饱和提亮到亮度 0.6；海报是灰的退回朱红 `#EA4E30`）；印章固定朱红 `#D8432A`。

**触摸规则（没有悬停）**
- 所有可点的行整行可点；按下 = 放大（按钮 1.04 倍回弹），不做压缩。
- 选中 / 当前项用三种记号，不靠颜色单独表达：实心小方块（单选）、反白格子（开关 / 分段）、专色标题 + 进度线（正在看的那一集）。
- 展开都是「推开」：筛选、排序、选季、服务器 / 账号切换、设置里的选择器，全部在触发它的那一行下面展开并把后面的内容推下去，不盖内容。唯一压在内容上的是更新提示（号外）和「再按一次返回」小条。
- 键盘弹起时标签栏让开；搜索结果下方留出键盘高度。

## 6. 哪些数据是编的

真实的：5 个媒体库和数量、继续观看 12 条和进度、最近添加、14 部详情（简介、评分、题材、演员和照片、音轨字幕流）、7 部剧的季和分集、航海王第 21 / 22 季分集、周星驰 23 部作品和角色、3 个合集的成员、12 个合集、全部海报 / 剧照 / logo / 分集缩略图。

编的（服务器给不了，按真实感写）：
- **编辑文案**：首页 8 期封面的导语和主编手记、各页她说的话、剧集页「主编按」。真实应用里导语 = tagline，没有时退回简介第一句。
- **发现页**：热播榜 / 冷门榜的名次和升降、「本周 37 次播放」、年代柱状图的数字、三张主编片单的名字。高分榜和新到榜是按真实评分 / 入库顺序排的。
- **日期和统计**：记录页的「今天 / 昨天 / 本周 / 更早」分组（导出里没有 lastPlayed）、读者证的 87 部看过 / 318 期、收藏页收藏了哪些片（服务器上真实的收藏只有颜心记第 5 集）。
- **多版本**：盗梦空间的第 2、3 个版本（4K 杜比视界 REMUX、1080p IMAX）及其音轨字幕；第 1 个版本和它的 1 条音轨 5 条外挂字幕是真实的。单集详情的「文件」四行。
- **播放器**：弹幕内容和条数、字幕文本、音轨 / 画质选项、码率、缓冲速度、片头片尾标记位置、错误信息。画面用的是颜心记的剧照，不是真实视频帧。
- **海报墙**：6 部超长片名样本的题材 / 评分 / 时长（数据包只给了片名、年份、海报）；「画质」筛选（4K / HDR / 杜比视界）按片名长度假分。

## 8. 播放器补充（横屏 905 × 412）

- 控件显示：顶栏（返回｜logo + 集名 + 规格｜她的一格｜收藏｜锁）、中间三个键、底部时间轴（弹幕热度圆点 + 片头 / 片尾刻度）和六个功能词（选集 / 字幕 / 音轨 / 倍速 / 画质 / 弹幕，各带当前值）。再点一下画面全部隐去，只留画面和字幕。
- 六个面板 + 片尾「下一集」都是同一种做法：画面缩到左边 75 %，右侧 170 px 页边排内容，底部功能词留着可以直接换面板。「画质」面板里同时有版本入口。
- 弹幕从顶栏下沿以下开始走，不和顶栏按钮叠。
- 贴边的提示都在角上 / 边上，带一小块墨色底，任何画面上都读得清，不占画面中央：跳过片头在右下（时间轴上方）；亮度条在左缘、音量条在右缘；快进量和长按 2× 在左上角（这时顶栏是隐藏的）；锁屏只留左缘一个锁。
- 缓冲：画面压暗 40 %，中间一条细线来回 + 速度；出错：画面拿掉，换成一页说明 + 四个出路（再试 / 换版本 / 服务器转码 / 复制错误信息）。
- 看完一集（整幅铺满）：左「本集完」+ logo + 她的一句话，右下一集的剧照和播放键；没有自动弹层挡画面——片尾进行中用的是右侧页边的「下一集」倒计时。
