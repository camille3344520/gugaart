# 咕咕嘎嘎 · B1「头版」· 电脑端（Windows）

- 入口：`index.html`（双击即可，需要支持 WebGL2 的 Chromium 内核浏览器）。左栏按界面清单分组，点一组，右边出这一组的画板；每块画板下面是状态按钮，关键界面多一排「窗口」按钮（1440 × 900 / 3168 × 1440 / 1100 × 720，播放器另有全屏和很窄）。
- 每块画板是一个真的窗口（`board.html?p=<界面>&st=<状态>`，窗口多大版式就按多大排），都是活的：能滚、能拖、能右键，点导航 / 海报会真的跳到别的界面。
- 截图：`shots/<界面>[-状态][-xl|-sm].png`，重拍 `node tools/shots.js [过滤词]`。
- 数据：`../data/library.json` + `extra.json` + `extra2.json`（`node tools/pack.mjs` 打成 `js/lib.js` 和 `pack/*.js`；玻璃引擎在 `file://` 下只能读 data URL，所以图片按张打包、用到哪张加载哪张）。

## 1. 相对 B1（手机）改了什么

1. **报头 = 窗口标题栏**。按三端统一稿（`../shared-masthead.md`）：左 `VOL. 318`，中「咕 咕 ◉ 嘎 嘎」（◉ = 品牌图里连帽衫的企鹅头圆形裁切），右日期，上实线下细线。电脑上它常驻在窗口最顶上，右端接着画窗口的最小化 / 最大化 / 关闭。普通页面滚动后它变成实心纸色带（滚动内容从它下面切过去，不叠字）；整幅铺满的页面顶部它是透明的，直接压在剧照上（剧照顶部有一条暗角保证读得清）。
2. **首页是跨页**。左页三维海报流（正中一张正对，两侧各两张向后转 54°；3168 宽时左页更宽、海报更大），右页是期号里程表、片名 logo、导语、续看、印章位、主编手记；3168 宽时多出第三栏「接着看」。两页之间是一条书脊细线。跨页背后是这一期的整幅剧照（虚化、压暗），翻到哪一期换哪一张。
3. **演员头像彩色**（剧集 / 电影详情的演职人员、人物页、同剧演员、搜索的人物结果），没有任何去色滤镜。没有照片的演员用姓氏字块代替。
4. **整幅铺满**（用户点名要多用的手法）：见第 3 节。详情页不再有顶栏下框起来的 16:9 图版。
5. **固定导航换到了报头下面一排**：左上返回圆钮、导航胶囊（首页 / 发现 / 片库 / 合集 / 我的，按住选中的可以拖透镜）、右上搜索胶囊（Ctrl K）和账号圆钮，全部是玻璃引擎渲染；账号菜单从圆钮里「长」出来（引擎的变形）。其余全部是纸面语言（细线、宋体、斜体数字）：下拉、右键菜单、对话框都是「纸片」，不是玻璃。
6. **手机的「下拉刷新 = 付印新刊」改成点报头的 VOL.（或 F5）**：期号滚成 319，封面回到第一期，她举翅膀说一句。
7. **卡片悬停**：海报朝鼠标倾斜 + 高光 + 专色投影；片名下面那一行换成快捷操作（播放 / 印章位 / 校对格 / 更多）。操作不压在海报上。
8. **新增界面**：发现、媒体库列表、合集列表 / 详情、单集详情、账号菜单、服务器 / 账号切换、设置九个分区、服务器列表 / 添加 / 登录、更新提示（号外）、右键菜单、播放器的十四个状态、错误态四种。
9. 导语不再手写：用 TMDB 的中文 tagline，没有就取简介的头一两句（真实数据）。只有「主编手记」是编的台词。

## 2. 布局规则

**单位**：`1rem = 10px @1440 宽`，随窗口宽度线性变化（1100 → 9.4px，3168 → 13px 封顶）。也就是说从 1440 到 3168，字和控件只放大 1.3 倍，剩下的宽度全部交给列数和跨页。

| | 1100 × 720 | 1440 × 900 | 3168 × 1440 |
|---|---|---|---|
| 页边 `--m` | 32 | 49 | 136 |
| 栏间距 `--gut` | 23 | 24 | 31 |
| 海报行（最近添加等）可见张数 | 6 | 7 | 11 |
| 海报墙列数（自动填充，最小卡宽 15.6rem） | 6 | 7 | 12 |
| 首页跨页 | 7 : 5 两页 | 7 : 5 两页 | 8 : 4.2 : 3.8 三栏（多「接着看」） |
| 继续观看 | 头条 + 5 行，再 3 + 3 | 同左 | 头条 + 两列目录 |
| 剧集详情正文 | 8 : 4（正文 / 资料） | 8 : 4 | 7 : 3 : 3.4（多「接下来」） |
| 电影详情正文 | 海报 / 正文，资料掉到下一行 | 海报 / 正文 / 资料 | 海报 / 正文 / 资料 / 同题材 |
| 分集卡片列数 | 3 | 4 | 8 |
| 评分榜 | 2 列 | 2 列 | 3 列 |
| 播放器面板宽 | 376 | 400 | 598 |

**竖向节奏**：报头 44；玻璃排在报头下 12 处、高 44；普通页面内容从 132 起。区块之间 56，区块标题（编号 + 宋体 26 + 斜体英文 + 通栏细线）到内容 16。

**字号阶梯（@1440）**：人物名 110 / 页面大标题 52–80 / 期号 96 / 评分 84 / 区块标题 26 / 正文导语 17–17.5 / 目录行标题 16.5 / 卡片标题 15 / 辅助斜体 12–13 / 英文小标 10.5–11.5（字距 .24em）。数字一律 Georgia 斜体，中文一律宋体，字幕和弹幕用黑体（那是画面里的字，不是版面的字）。

**颜色**：墨黑纸 `#100E0B`、米白字 `#EFE6D4`、细线 18 % 米白；专色 `--spot` 取自当前海报最强的色相、提亮到 60 % 亮度（灰海报退回朱红 `#EA4E30`）；印章固定朱红 `#D8432A`，不跟专色；玻璃导航选中小圆点保持朱红。

**悬停规则**：海报卡 = 倾斜 + 高光 + 专色投影 + 快捷操作行；目录行 / 资料里的人名 = 标题变专色；按钮 = 放大 3 %（按下 6 %，不是缩小）；窗口键 = 浅底，关闭键红底。
**焦点规则**：键盘焦点环（2px 米白线，外扩 4px）只在按过 Tab / 方向键之后出现，鼠标一按就消失（`body.kb`）。截图 `home-focus`。
**滚动**：没有常驻滚动条；首页封面跨页与目录区之间有吸附（滚一下翻一页）。横向海报行：Shift + 滚轮或触控板横滑。
**按钮压在图上**：只有玻璃排压在图上。导航胶囊靠左、搜索和账号靠右，正中留空（大多数剧照的主体在中间）；剧照顶部 0–130px 有一条由深到浅的暗角（是真实元素，玻璃折射的就是压暗后的图）；右缘竖排图注默认在右上，遇到右边缘有人脸的图（颜心记）往下挪到衣服的位置。

## 3. 整幅铺满用在哪

| 界面 | 做法 |
|---|---|
| 首页封面跨页 | 这一期的剧照铺满整个第一屏（虚化压暗，海报流和文字在上面），翻期时交叉淡入 |
| 发现 · 今日专题 | 剧照从窗口顶端铺到 76 % 屏高，logo / 导语 / 评分接在渐隐处 |
| 剧集详情 | 剧照铺到 72 % 屏高；报头、返回、导航、搜索压在图上；右缘竖排图注 |
| 电影详情 | 同上（66 %），海报压在渐隐处、悬停时倾斜 |
| 合集详情 | 合集自己的剧照铺满，合集名用宋体大字 |
| 人物页 | 大照片占窗口右半边、从顶端铺到第一屏底，向左渐隐进纸面 |
| 搜索 · 最佳匹配 / 人物只有 1 部 | 16:9 大图 + logo 压在图下沿（图版，不是全窗） |
| 播放器 | 播放中画面铺满整个窗口；暂停 / 控件出现时画面「退一步」让出页边 |
| 没有剧照的片子 | 用海报放大虚化铺满，竖排图注写明「没有剧照 · 用海报虚化代替」（截图 `movie-long`） |

## 5. 咕咕嘎嘎在这一端放在哪、为什么不挡

都是版面里专门留给她的一格，跟着页面走，不叠在内容上；不弹气泡、不做浮层；她说的话写进她那一格旁边的一行字里。

| 位置 | 形式 |
|---|---|
| 首页右页页脚「主编手记」 | 圆形署名照（活的分层立绘：眼睛跟鼠标、眨眼、盖章时举翅膀）+ 一行手记 |
| 剧集详情简介下面「主编按」 | 同上；换集时说话 |
| 我的 ·「读者证」左格 | 同上 |
| 登录页表单上方 | 同上；密码框获得焦点时闭眼 |
| 播放器顶栏右侧一格 | 播放时这一格是空的；暂停才出现。正在播放的画面上永远没有她 |
| 首次加载 / 片库加载 | 轮廓占位：低头摆稿纸 |
| 搜索空状态 / 搜不到 / 筛不到 / 收藏为空 | 轮廓占位：举笔、摊手、捧白纸 |
| 首页末尾 | 轮廓占位：趴着打盹 |
| 更新提示（号外）正文下一行 | 轮廓占位：举着刚印好的号外 |
| 错误页右页 | 轮廓占位：举着拔掉的插头等（整页错误没有别的内容，右页是留给她的） |

## 7. 哪些是真的、哪些是编的

**真的（来自数据包）**：5 个媒体库和部数 / 集数；继续观看 12 条和进度（0 %、7 %、59 %、79 %…）；所有片名、年份、评分、类型、简介、tagline、分级、出品方；演职人员和彩色照片；分季分集（颜心记 40 集、航海王 22 季 1215 集及第 21 / 22 季的分集、龙珠大魔、网球王子、谷雨…）；周星驰 23 部作品和角色名；12 个合集及 3 个合集的成员和剧照；电影的媒体流（视频 / 音轨 / 字幕表）；全部图片。

**编的**：
- 主编手记 / 主编按 / 她说的每一句话；期号 VOL. 318、日期、读者证编号。
- 用户名「影迷」「小满」「访客」，服务器名「家里的片库」「办公室 NAS」「朋友的服务器」及其状态、延迟。
- 记录页按「今天 / 昨天 / 本周」的分组（条目和进度是真的，日期分组是摆的）；「本月看完 41 集」；收藏的九部是我挑的。
- 电影的多版本：第一条是真实媒体源，「4K · HDR10 · REMUX」「导演评论音轨」两条是编的（界面上带「编的」小标）。
- 播放器：弹幕内容、字幕那一句台词、字幕 / 音轨 / 画质列表、缓冲速度、出错原因和日志、热力图曲线、章节（片头 / 片尾）位置；播放的「画面」是剧集的剧照，不是真实截帧。
- 单集详情里的规格行（1080p · H.264…）、筛选里的「规格」一组、设置里的缓存占用 / strm 测试结果、更新提示的版本号、大小和更新条目、搜索的「最近搜过」。
- 设置的分区名和大部分选项名取自原生应用的设置树（`SettingsSections.kt`），说明文字有改写。

## 9. 已知的小出入

- 玻璃折射的是页面内容的一份重绘（适配层只认图片、纯色、线性渐变、文字、图标）：首页跨页背后的虚化剧照在玻璃里是没虚化的压暗版；三维倾斜的海报在玻璃里按外接矩形画。真机上着色器直接取屏，没有这个问题。
- 滚动时，内容会从玻璃排下面经过、在报头下沿被切掉（硬切，不是渐隐）；这是为了让玻璃有东西可折射、同时报头不叠字。
- 播放器的画面是剧照；只有「跳过片头」是浮在画面右下角的玻璃胶囊，其余控件都在页边里。片尾「下一集」不盖画面：画面往左让，下一集排在右边的页边（带她鼓掌的轮廓占位 H15）；进度条悬停预览是一张小横条，落在底部页边里，不压画面。
- 海报墙「本稿收录 N 部」= 数据包里实际有的条目数，小于媒体库真实部数。
- `js/engine.js` `core.js` `glass.js` `sprite.js` `mascot.js` `poses.js` 从 `../../fable-huabao/js` 原样复制，没有改动。
